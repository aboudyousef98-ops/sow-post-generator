# 08 — Higgsfield 3-Day Sprint

The window is started by us, so it opens only when the checklist below is complete. Confirm the Higgsfield MCP's current tools, limits and export formats on the day before; details here are a plan, not a spec of the product.

## Ready-to-start checklist
- [ ] Brand kit final (palette, fonts, logo SVG/PNG).
- [ ] 50 post briefs approved, each with prompt, aspect ratio, duration, caption.
- [ ] Reference images prepared: sample plan sheets, roof plans, logo, style frames.
- [ ] Website hero/section video needs listed.
- [ ] File naming and folder structure created.
- [ ] MCP connected and one test generation done on a free/low tier.

## What to generate
| Asset | Qty | Spec |
|---|---|---|
| Reels (line-draw, sheet anatomy, process) | 15–20 | 9:16, 6–15 s |
| Carousel cover art / backgrounds | 30+ | 4:5 |
| Website hero loop + section loops | 4–6 | 16:9, seamless |
| LinkedIn cover and post visuals | 10 | 1.91:1 and 1:1 |
| Spare variations | 2–3 per hero asset | |

## Schedule
- **Day 1:** style lock. Generate style frames, pick the look, then all still images.
- **Day 2:** all video: reels and website loops. Re-roll weak ones the same day.
- **Day 3:** variations, repurposed cuts, gaps, exports, backup.

## Prompt template
`[subject] + [blueprint style: deep navy background, white technical linework, amber accent, drafting grid] + [camera/motion] + [duration/ratio] + [negative: no people, no logos of real brands, no text]`

Add text and labels afterwards in Canva/Figma; generated text is unreliable.

## Content limits
- No fake crews, trucks, offices, client homes presented as ours.
- No real brand logos or identifiable people.
- Every asset logged with its prompt for re-use.

## Naming
`[series]-[nn]-[format]-[v].ext`, e.g. `codenotes-03-reel-v2.mp4`. Store in cloud drive; do not commit large media to git.
